## Tarea 3 - Análisis Geoespacial de la Industria de los Videojuegos

### Consideraciones:
- Para instalar las dependencias y poder ejecutar todos los codigos sin problemas, estando dentro de la carpeta ```./Tarea-3``` se debe ejecutar:  
```pip install -r requirements.txt```
- La carpeta ```./Codigos```, contiene una carpeta por cada integrante del grupo. Dentro de cada carpeta personal y grupal, se encuentra un archivo de extensión “.py” y/o una imagen con la visualización realizada por la herramienta seleccionada.
- La carpeta ```./data```, contiene la carpeta ```./raw``` con la fuente de datos intacta y la carpeta ```./clean``` que cuenta con el dataset limpiado, utilizando códigos también presente en esa carpeta para limpiarlo y concatenar los paises junto a sus latitudes y longitudes.
